# ui

One design skill on top of `emil-design-eng`, `apple-design`, and `animate`. Coding lives in
`dev`; this bucket only covers how the UI looks, moves, and feels.

This bucket is its own Claude Code plugin (`claude plugin install ui@skrrt`), so its skill is
namespaced `/ui:design`.

- **[design](./design/SKILL.md)**: Load the craft skills, study modern products, show variants, build with care, and check it on screen.
