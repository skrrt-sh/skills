# ui

UI craft that complements the motion skills such as `emil-design-eng`, `apple-design`, and
`animate`. Motion stays with those skills; these cover everything around it.

This bucket is its own Claude Code plugin (`claude plugin install ui@skrrt`), so its skills are
namespaced `/ui:<name>`.

- **[design-system](./design-system/SKILL.md)**: One visual system: tokens, one component per pattern, full component states, stable sizes, and fixes made in the system.
- **[screens](./screens/SKILL.md)**: Complete, predictable, fast screens: every state, known UX patterns, rendering only what is visible, matched to the design and checked in the real UI.
