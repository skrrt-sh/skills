# ui

UI craft that complements the motion skills such as `emil-design-eng`, `apple-design`, and
`animate`. Those skills own motion technique; `motion` layers this project's settings on top.

This bucket is its own Claude Code plugin (`claude plugin install ui@skrrt`), so its skills are
namespaced `/ui:<name>`.

- **[ux-patterns](./ux-patterns/SKILL.md)**: Design from user stories, then established UX patterns for the platform, then a few chosen principles. No design for its own sake.
- **[taste](./taste/SKILL.md)**: How a page looks and reads: keep what works, one grid, restraint with decoration, plain copy said once.
- **[motion](./motion/SKILL.md)**: Project motion settings on top of Emil Kowalski's and Apple's motion skills: few small accents, one motion language, smooth and interruptible.
- **[design-system](./design-system/SKILL.md)**: One visual system: tokens, one component per pattern, full component states, stable sizes, and fixes made in the system.
- **[screens](./screens/SKILL.md)**: Complete, predictable, fast screens: every state, known UX patterns, rendering only what is visible, matched to the design and checked in the real UI.
