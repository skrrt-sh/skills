# Follow-up review requests

Identify the relevant PR or MR from a user-supplied number or by matching keywords, changed files,
and recency. Ask when more than one candidate is plausible.

- **Open:** update its source branch and existing request; do not open another.
- **Merged:** start a fresh branch from its target and open a new request.
- **Closed unmerged:** ask whether to reopen/reuse it or start fresh.

Confirm the outgoing commits belong to the chosen request before pushing.
